🧠 Objective

This project is inspired by a YouTube tutorial and aims to analyze the online sales performance of Madhav Store across India using Power BI.

📂 Data Description

Two CSV files were used:
1️⃣ Orders Table: Order ID, Order Date, Customer Name, State, City
2️⃣ Details Table: Order ID, Amount, Profit, Quantity, Category, Sub-Category, Payment Mode

⚙️ Key Steps

Data cleaning and transformation in Power Query

Building relationships between Orders and Details tables

Creating interactive visuals and KPIs

Using slicers and filters for deeper insights

📈 Dashboard Highlights

Sales & Profit by State and City

Category & Sub-category Performance

Payment Mode Insights

Quantity and Customer Order Analysis

🧩 Skills Used

Power BI | DAX | Data Cleaning | Data Modeling | Data Visualization | Analytical Thinking
